# Security policy

Supported public release series: 1.0.x once published. Until release blockers are closed, artifacts are release candidates, not a security certification.

Report vulnerabilities privately through GitHub Security Advisories once the repository is created (maintainer: enable private vulnerability reporting). Do not publish exploit details, credentials or personal media in issues. If the feature is unavailable, contact the maintainer via the support links in the app to arrange a private report.

Only install artifacts from the maintainer's Releases page. Verify SHA256SUMS and the signing certificate fingerprint in the release report. Hashes detect download changes; trust still depends on the publisher/channel.

Obfuscation does not make code or model weights unextractable. The repository deliberately publishes the app source. Vendor SDK components have separate licenses and are not fully open source.
