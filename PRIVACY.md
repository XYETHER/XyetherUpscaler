# Privacy

This version processes selected images and videos locally on the device. It uses Android media import/export APIs and saves output to Gallery. Temporary copies and inference caches may remain in app storage until cleared. Android backup behavior is disabled in the prepared release to reduce copying of local media/cache data.

The application does not implement a remote model service, announcement push service, user account, advertising or analytics SDK. Support/social buttons open external sites governed by their own policies. Installing via GitHub involves GitHub's policies; processing does not require sending media to GitHub.

Clear app storage/uninstall to remove app-private files; saved Gallery outputs must be removed separately. Do not post private media or unredacted logs in public issues.

This describes the inspected application code, not a third-party binary network-traffic certification.
